# abhaybe.github.io

Personal site. Plain Jekyll, no theme or plugins, built natively by GitHub Pages.

- `index.html`: homepage (bio, experience, projects, writing, honors)
- `_posts/`: blog posts in Markdown (`YYYY-MM-DD-slug.md`, served at `/blog/slug/`)
- `assets/css/style.css`: all styling, with light and dark mode
- `assets/files/`: resume PDF
- `DOMAIN_SETUP.md`: steps for pointing a custom domain at the site

Local preview: `jekyll build` then serve `_site/` (for example `python3 -m http.server -d _site`).
